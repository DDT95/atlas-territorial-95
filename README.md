# Atlas territorial du Val-d’Oise

Socle cartographique de la Direction départementale des territoires du Val-d’Oise (DDT 95).

## Observatoires reliés

- [Agriculture](https://ddt95.github.io/agriculture95/)
- [Risques majeurs](https://ddt95.github.io/observatoire_risques_95/)
- [Bâti et habitat](https://ddt95.github.io/observatoire_bati/)
- [Transports](https://ddt95.github.io/transport95/?v=1ac3c80)

Le socle comprend également les modules locaux Urbanisme à la parcelle, Agriculture, Risques et Habitat, ainsi que les emplacements des prochaines thématiques.

## Développement local

Prérequis : Node.js 22.13 ou version ultérieure.

```bash
npm install
npm run dev
```

L’Atlas est alors disponible sur `http://localhost:3000`.

## Vérification

```bash
npm run build
```

## Sources principales

IGN, INSEE, Géorisques, API Carto, CartoBio, ADEME, DRIEAT et autres référentiels publics documentés dans chaque observatoire.
